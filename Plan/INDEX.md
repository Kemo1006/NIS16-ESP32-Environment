# Plan/ — Thesis 3 planning & brainstorm

**All CTTHES3 planning lives here.** Design thinking, panel-response plans, matrix designs, literature notes, open questions — anything that is *deciding what to do* rather than *doing it*.

Not here: executed work (→ the repo), finished results (→ `Paper/`), retired Thesis 2 material (→ `0_Resources/archive/`).

> **Path convention:** paths written in these documents are relative to the **workstation root** (`Thesis_workstation/`), except paths inside a repo-scoped table, which are relative to `NIS16-ESP32-Environment-semi-final/`. Each document states which it means.

## Adding to this folder

- One concern per file; name them `THESIS3-<TOPIC>.md`.
- Add a row above when you add a file. This index is the only thing that needs reading to know what's here.
- When a plan is executed and superseded, move it to `0_Resources/archive/` rather than deleting it — the reasoning stays useful when the panel asks "why did you do it that way?"
