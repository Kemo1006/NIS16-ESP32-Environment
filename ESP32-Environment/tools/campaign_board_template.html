Field sessions

One session is one location and one topology: place the 8 boards once, run blackhole, then the benign run, then wire the A↔B cable for wormhole. The location with the most done runs comes first.

Scenario coverage

Ticks come from the files on disk (tools/inventory_cells.py), not from memory: a run counts as done only when its CSVs pass the M4/M5 checks and the analysis ran after the export. Time estimate: min per run, plus 20 min to place the boards for a new topology and 10 min to wire the tunnel. Refresh: python tools\inventory_cells.py --json campaign_status.json, then republish.
